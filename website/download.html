Download

PadSampler is free on Windows and on Android (Google Play). Both are built from the same open source code.

Windows

Free · Windows 10 / 11, 64-bit

PadSampler for Windows

Installer with everything included (no Java or other software needed). About 100 MB.

Download the latest version All versions

On the release page, download PadSampler-x.y.z.exe under "Assets".

Installing

  1. Run the downloaded .exe. It installs for your user only, no administrator rights needed.
  2. Windows SmartScreen may say "Windows protected your PC", because the installer is not signed with a paid certificate. Click More info → Run anyway.
  3. Start PadSampler from the Start menu or desktop shortcut, open ⚙ and choose your audio output (see the manual).

To update, install the new version over the old one; your sessions and settings stay. To uninstall: Windows Settings → Apps → PadSampler. Your sessions remain in %APPDATA%\PadSampler until you delete that folder.

For the lowest latency use an audio interface with an ASIO driver. WASAPI works with any sound card.

What you need

  • Audio: wired headphones, speakers or an audio interface. Bluetooth has too much delay for playing live.
  • Optional: Novation Launchpad Mini MK3 (USB; on Android with a USB-C OTG adapter), any class-compliant USB MIDI keyboard.
  • Optional: Ableton Live or another Link app on the same Wi-Fi for tempo sync.

Build it yourself

PadSampler is free software. The build instructions for Android and Windows are on GitHub.
