Source code

The complete source code of PadSampler (Android and Windows) is on GitHub:

github.com/rasxxb-hash/padsampler

Every released version is tagged there, so the source for any Windows installer or Google Play release can always be found. The Android version on Google Play is a paid build of exactly this code; you are free to build it yourself (instructions).
